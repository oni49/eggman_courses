## Session 1 — The Automation Problem

*A conceptual framing session — light on canon by design. One anchor worth reading now, because it argues the same thesis: the model is one component, and the value lives in the scaffolding around it.*

- **Go deeper** — Anthropic, "Building Effective Agents" (engineering blog, 2024). Lays out the distinction between fixed *workflows* and open-ended *agents*, and argues for the simplest scaffolding that works — the practitioner's version of "the model is the least interesting part." The spine for Sessions 5–6. Pull the current version from anthropic.com.

*Reference spine to come as sessions land: the original RAG paper (Session 2), the ReAct paper on reason/act interleaving (Session 5), the Model Context Protocol specification (Session 4), and OWASP's LLM Top 10 (Session 7). Named here as a roadmap, not yet as citations — each gets its full entry when we reach it.*
